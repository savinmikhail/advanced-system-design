## Домашнее задание

В качестве домашней работы предлагаю вам настроить сбор и визуализацию метрик для вашего веб‑приложения.

### Цель

Нужно будет создать дашборд в графане, где будут отображаться:

- RPS
- Latency - p50 и p99
- количество и доля серверных ошибок за выбранный интервал времени

### Что нужно сделать

Для этого 

1. Напишите или возьмите готовое приложение на своём стеке
2. Собирайте логи и метрики
3. Настройте Grafana
4. Через k6 сгенерируйте нагрузку
5. Убедитесь, что графики реагируют.

Разбор моего решения будет опубликован на Boosty.
